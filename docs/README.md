# power-loop Documentation

[English](en/index.md) | [中文](zh/index.md)

**power-loop** is an embeddable Agent execution kernel for Python. It provides LLM abstraction, multi-turn conversation, tool calling, lifecycle hooks, event bus, declarative sub-agents, context compaction, and session persistence — everything you need to build an AI agent without a framework framework.
